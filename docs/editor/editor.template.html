        How this works

        Four short pages: build, edit, check or solve, export.

        Components
        Search Network, Physical and Annotations. Click a component then place it, or drag a network part. Properties stay beside the selected object. On narrow screens Components opens a drawer.
        Quick add
        Right-click empty space or press / outside a text field, then type a component name. On touch, hold empty space for half a second; moving or pinching cancels. An ordinary empty-space click only deselects.
        Adding and joining
        Drag a component onto the drawing, or click it and then click to place. Sources attach when dropped onto a highlighted node. Path endpoints can attach to highlighted nodes; the body never merges nodes. Drag an endpoint handle, or click it and then its target. A red dot marks a loose end. Double-click a node to start a connection.
        Rectangular sketches
        Use Components → Physical to add regions and control volumes by dragging opposite corners, then resize with corner handles. Shift-click multiple rectangles, then drag an edge handle to adjust all widths or all heights together. Add surfaces to volume edges and transfers to surfaces. Region membership is explicit. Select objects together to move their network associations too.
        Labels
        Drag a label to position it. Auto position in its card restores automatic placement. Auto-position all labels resets the whole drawing in one undo step.
        Turning
        [ and ] turn the selected network component to the next quarter turn. Text fields accept brackets normally. Rectangles stay axis aligned.
        Copy and paste
        Ctrl+C copies selected objects; Ctrl+V pastes an offset copy with new IDs. Groups retain internal connections. Control volumes carry their surfaces and transfers. Text fields keep normal text copying and pasting.
        Undo, Redo, Delete
        Each movement is one undo step. Esc, pointer cancellation and pinch restore the committed drawing. Delete removes the selection and its owned geometry; affected balances become incomplete.
        Fit to screen
        Brings the whole drawing into view. Scroll to zoom, drag empty space to pan, pinch on touch. Shift-click adds to the selection; Shift-drag empty space selects a group. Alt bypasses grid and alignment snapping.
        Notation
        Textured boxes, the default, or circuit zigzags for every resistance. Nothing else moves.
        Theme, Present
        Light or dark page. Present shows the drawing alone, full window: Esc leaves, ← → step through your files.
        Solve physics
        Numeric values start Known. Click a schematic badge to cycle its supported states; click a component or list row to edit. Overrides appear on the drawing until you close Solve. Readiness explains missing inputs and solver limits. Choose the steady-state time model, solve, then review and apply in one undoable step.
        Check the numbers
        Checks network node balances and supplied control-volume energy rates independently. Select a volume for signed totals. Supply generation, including zero, and storage or steady state; missing inputs remain unchecked. Drawing dimensions never imply physical area.
        Units & rail
        The unit of each quantity, whether K is absolute or a rise, and the reference rail.
        Copy share link
        A link that carries the whole diagram inside it. Nothing is stored on any server; whoever opens it gets a copy.
        Export
        Export for document previews a tightly cropped light SVG, with Save SVG and Save PNG. Other choices include themed SVG, HTML and the JSON file itself.
        Files
        Everything you draw is kept in this browser, saved as you go. New, Example and Import make a file; rename, copy and delete are in each file's menu. A diagram's name can travel inside the file too, so an export or a share link carries it.

        Keys: Ctrl+Z undo · Ctrl+Shift+Z redo · Delete · Esc · [ ] turn · F fit · Z notation · D theme · P check the numbers.
