        How this works

        Four steps on your own drawing: add, connect, edit, check.

        Undo, Redo, Delete
        The last change back or forward; the selected component removed with what hung on it.
        Fit to screen
        Brings the whole drawing into view. Scroll to zoom, drag empty space to pan, pinch on touch.
        Notation
        Textured boxes, the default, or circuit zigzags for every resistance. Nothing else moves.
        Theme, Present
        Light or dark page. Present shows the drawing alone, full window: Esc leaves, ← → step through your files.
        Check the numbers
        In the strip at the bottom. Adds a heat balance at every node: what arrives must leave, from the values you typed.
        Units & rail
        The unit of each quantity, whether K is absolute or a rise, and the reference rail.
        Copy share link
        A link that carries the whole diagram inside it. Nothing is stored on any server; whoever opens it gets a copy.
        Export
        SVG that follows light and dark, SVG baked for Word and slides, PNG, the HTML page with its controls, or the JSON file itself.
        Files
        Everything you draw is kept in this browser, saved as you go. New, Example and Import make a file; rename, copy and delete are in each file's menu. A diagram's name can travel inside the file too, so an export or a share link carries it.

        Keys: Ctrl+Z undo · Ctrl+Shift+Z redo · Delete · Esc · F fit · Z notation · D theme · P check the numbers.
